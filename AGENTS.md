# TaskFlow
Usa npm ci y el lockfile versionado. Node >=22.12. Todas las claves VITE son públicas.
Especialistas disponibles en .opencode/agents; skills en .opencode/skills.
Nunca leas ni imprimas secretos. Nunca subas .env. No fabriques commits de otros integrantes.
Todo cambio se trabaja en feature/* desde develop, con PR y revisión real.
Criterio de terminado: npm test, npm run build, documentación y RLS externo cuando corresponda.
MCP no es necesario: archivos locales, SQL y cliente oficial cubren el flujo. Agregar uno exige justificar el servicio y permisos mínimos.
